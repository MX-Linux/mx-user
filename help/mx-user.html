HELP: MX User Manager

General

This application has 5 tabs.

  • Administration: add, delete and rename users, and change passwords.
  • Options: reset the selected user’s Mozilla configuration or group memberships, and choose whether the user logs in automatically.
  • Copy/Sync: copies or synchronizes a user’s whole Home, Documents, Shared folder or Mozilla configuration to another user’s Home or to a folder you choose. If you use a browser not made by Mozilla, copy its configuration folder by hand.
  • Add/Remove Groups: self-explanatory.
  • Group Membership: allows root to change a given user’s access to services and applications.

Notes

Options tab: Restore defaults

  • Mozilla configs deletes the selected user’s ~/.mozilla folder and the Firefox profiles stored in it: bookmarks, saved passwords, history, extensions and settings. No backup is made, and the deletion cannot be undone. Firefox creates a new, empty profile the next time it starts. To keep a way back: close Firefox for that user, copy ~/.mozilla somewhere safe (for example with the Copy/Sync tab to a folder you choose), and only then reset.
  • Group memberships replaces the user’s supplementary groups with the default extra groups configured in /etc/adduser.conf. Membership in the administrator group (sudo or wheel) is kept.
